Notes and agents in one workspace.

Write notes on your Mac and talk to Claude Code or Codex beside them. The agent edits your notes directly, and every edit has Undo.

Download Barkdown for MacFinding the newest version…

There is no stable release yet. This is the newest nightly: built from the latest code and installed, opened and tested on both kinds of Mac before it was published.

Needs macOS 13 Ventura or later.

Signed and notarized by Apple, so it opens like any other app.

Get started in three steps

  1. Install it

    Open the downloaded file and drag Barkdown into Applications.

  2. Open it

    Start Barkdown from Applications. Your notes are kept on this Mac, in a library Barkdown runs for you. No account needed.

  3. Connect an assistant

    Barkdown works with the assistant you already use. Pick one, then click Set up an assistant in Barkdown.

    • Claude CodeInstall Claude Code, then sign in from Terminal:
      claude auth login
    • CodexInstall Codex, then sign in from Terminal:
      codex login
    • A Claude API keyPaste it in Barkdown's Settings, under Assistant.

Updates

Barkdown checks for new versions. Settings, under About, shows one when it's ready and installs it when you click. It copies your library before it does.

Your notes stay yours

Notes live in a library on your Mac. Removing the app leaves them where they are; installing it again opens the same library.

Check the download

Every release lists a SHA-256 checksum for each file. In Terminal: shasum -a 256 ~/Downloads/Barkdown-*.dmg

Barkdown is free and open source, built on Barkpark. Windows version not available yet.
