## Additional source finding: unsaved project buffers

`renderer/src/index.js:54` calls `dirtyCount()` before profile switching. `renderer/src/tabs/project.js:18` counts only keys beginning `root + '::'`; without a root, normal buffer keys never match `undefined::`. The intended guard therefore appears ineffective for ordinary dirty project buffers. Profile selection reloads the renderer; the buffer Map is session-only and keyed `folder::file`, not profile. This is a concrete source mismatch, **not yet an observed UI-loss claim**. Prepare a disposable same-folder A/B reproduction; do not modify behavior during C016's pending dual-runtime proof.
