# Local Paper deletion and recovery

C071 candidate: an owned local draft can be deleted with a revision fence and recovered as a separate copy. Deleted notes is separate from the unplaced Archive. Original Pages, favorites, links and tabs retain their identity. Recovery does not restore an original ID or roll back later human edits.

The [cycle handoff](../../cycles/C071-paper-deletion-recovery.md) owns current validation. Native candidate captures are retained under `runs/`; final source-bound capture and named image/motion review are pending. This page does not claim visual acceptance yet.

The backend journal is written before deletion. Lost replies reconcile exact history without replaying deletion. Copy recovery reuses a durable creation identity. An unavailable older server refuses the new operation; it never falls back to generic both-variant deletion.
