# Agents on ordinary Paper notes

C069 adds shared API/MCP creation, discovery and editing for managed-local Paper notes. The runtime captures the profile; exact draft rows and opaque library owners survive activity, receipts and restart. Creation uses one request UUID and original content; uncertain results reconcile that request instead of creating a replacement.

Native acceptance is in progress in [C069](../../cycles/C069-agent-paper-notes.md). Real disposable-server and stdio MCP probes pass; reviewed native media will be linked here before acceptance. No new screenshot is claimed by this placeholder.

Body replacement preserves the locked title. Guarded Undo requires the acknowledged revision and original owner, retaining later human edits. Agent title editing, creation deletion, uncertain edit-response recovery, migration activation and legacy retirement remain outside this proof. Additional locked slots require targeted edits; whole-body replacement refuses them.

The native harness uses scripted model responses through the actual SDK and real Paper runtime. It is distinct from authenticated-provider and deterministic fixture-tour evidence.
