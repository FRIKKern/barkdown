# Third-party material

- Portable previews embed the Lucide UMD icon library from the exact npm version in `package-lock.json`. Its license is reproduced in `preview/LUCIDE-LICENSE.txt`. Build tools and browser test dependencies retain their own installed notices.
- T3 Code is a proposed runtime foundation. No T3 runtime source is included in this initial handoff. Before importing it, retain its MIT license and copyright notice from the selected revision and audit its dependency notices and distribution requirements.
- Barkdown includes Barkpark's production Paper editor JavaScript/CSS as a vendored fallback in `app/renderer/vendor`, alongside a Mermaid helper and Barkdown's adapted popup styles. The current fallback is pinned by `app/BARKPARK_REF`; `BARKPARK-LICENSE` retains the upstream Apache-2.0 license. The connected server or verified cache may supply a different build. [Consumption provenance and limits](docs/EDITOR-CONSUMPTION-AUDIT.md) distinguish those paths.
- [Paper editor dependency notices](docs/third-party/paper-editor/README.md) preserve 49 exact bundled package versions for the selected 54579 fallback, including official matching-release Tiptap texts missing from its installed package payloads. The notices and release provenance are also shipped beside the assets in `app/renderer/vendor/paper-editor-notices`, covered by the renderer/** packaging rule. Preserve the popup extraction's historical MIT header separately: it differs from current upstream's Apache-2.0 license and must not be silently rewritten or used to relabel the complete bundle.
- The Tiptap Notion-like template is a design reference, not vendored source. Its commercial template terms are separate from the installed Barkpark editor's Tiptap dependencies. Verify entitlements before any reuse of template code.
- Interface images and recordings in `docs/images` and `docs/visual` include both historical concept captures and actual Barkdown/Paper test evidence. Their manifests, galleries and review records identify source and limitations; a concept capture is not live behavior proof. Unrelated desktop screenshots from the conversation are not included as product evidence.

No new open-source license is granted for original Barkdown material by this private handoff.
