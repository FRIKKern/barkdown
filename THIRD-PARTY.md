# Third-party material

- Portable previews embed the Lucide UMD icon library from the exact npm version in `package-lock.json`. Its license is reproduced in `preview/LUCIDE-LICENSE.txt`. Build tools and browser test dependencies retain their own installed notices.
- T3 Code is a proposed runtime foundation. No T3 runtime source is included in this initial handoff. Before importing it, retain its MIT license and copyright notice from the selected revision and audit its dependency notices and distribution requirements.
- Barkpark source is referenced through immutable GitHub links. Its production editor and server code are not copied into this handoff. Review the applicable source license and packaging boundary before importing or extracting code.
- The Tiptap Notion-like template is a design reference, not vendored source. Its commercial template terms are separate from the installed Barkpark editor's Tiptap dependencies. Verify entitlements before any reuse of template code.
- Interface images in `docs/images` are captures of our own working concepts. Unrelated desktop screenshots from the conversation are intentionally not bundled.

No new open-source license is granted for original Barkdown material by this private handoff.
