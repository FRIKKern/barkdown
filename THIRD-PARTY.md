# Third-party material

- Portable previews embed the Lucide UMD icon library from the exact npm version in `package-lock.json`. Its license is reproduced in `preview/LUCIDE-LICENSE.txt`. Build tools and browser test dependencies retain their own installed notices.
- T3 Code is a proposed runtime foundation. No T3 runtime source is included in this initial handoff. Before importing it, retain its MIT license and copyright notice from the selected revision and audit its dependency notices and distribution requirements.
- Barkdown includes Barkpark's production Paper editor JavaScript/CSS as a vendored fallback in `app/renderer/vendor`, alongside a Mermaid helper and Barkdown's adapted popup styles. The current fallback is pinned by `app/BARKPARK_REF`; `BARKPARK-LICENSE` retains the upstream Apache-2.0 license. The connected server or verified cache may supply a different build. [Consumption provenance and limits](docs/EDITOR-CONSUMPTION-AUDIT.md) distinguish those paths.
- [Paper editor dependency notices](docs/third-party/paper-editor/README.md) preserve 49 exact bundled package versions for the proposed 54579 consumption follow-on, including official matching-release Tiptap texts missing from its installed package payloads. This archive does not update the current fallback; the follow-on must ship the notices beside its assets. Preserve the popup extraction's historical MIT header separately: it differs from current upstream's Apache-2.0 license and must not be silently rewritten or used to relabel the complete bundle.
- The Tiptap Notion-like template is a design reference, not vendored source. Barkdown's own Tiptap packages were removed with the legacy editor on 2026-09-30 (C087); the Barkpark editor bundle carries its own. Verify entitlements before any reuse of template code.
- Interface images and recordings in `docs/images` and `docs/visual` include both historical concept captures and actual Barkdown/Paper test evidence. Their manifests, galleries and review records identify source and limitations; a concept capture is not live behavior proof. Unrelated desktop screenshots from the conversation are not included as product evidence.
- A macOS application built by `scripts/build-mac-app.mjs` carries more than this repository: the Barkpark server release with its Erlang/OTP runtime and Elixir packages, PostgreSQL 15 built from the official source, and OpenSSL 3 linked statically into it. [Notices for the carried runtime](docs/third-party/runtime/NOTICES.md), generated by `scripts/collect-runtime-notices.mjs`, list every carried component with its licence and keep each licence text. A build is handed to another person only with those notices beside it ([C086](docs/cycles/C086-packaged-runtime.md)).

No new open-source license is granted for original Barkdown material by this private handoff.
